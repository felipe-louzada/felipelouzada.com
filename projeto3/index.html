Previsão de Séries Temporais

Python Statsmodels Jupyter Forecasting

Aplicação de modelos de forecasting para prever demanda futura com base em dados históricos, utilizando técnicas estatísticas e redes neurais para planejamento estratégico.

Contexto

O problema

Prever com precisão a demanda futura é um desafio crítico para qualquer negócio. O projeto buscou desenvolver um pipeline de forecasting que capturasse tendências, sazonalidade e padrões irregulares nos dados históricos.

Abordagem

Metodologia

  • Análise de estacionariedade com testes ADF e KPSS
  • Decomposição da série em tendência, sazonalidade e resíduo
  • Modelagem com ARIMA, SARIMA e Prophet
  • Comparação com LSTM para capturar padrões não-lineares
  • Avaliação com MAPE, RMSE e validação cruzada temporal
Resultado

Impacto gerado

O modelo Prophet combinado com ajuste manual de sazonalidade atingiu MAPE de 8.3% no conjunto de teste, superando o baseline naive em 43%. As previsões foram utilizadas para planejamento de estoque e alocação de recursos com horizonte de 3 meses.

Ferramentas

Stack utilizada

  • Python como linguagem principal
  • Statsmodels para modelos ARIMA e SARIMA
  • Prophet (Meta) para forecasting com sazonalidade
  • TensorFlow/Keras para a rede LSTM
  • Jupyter Notebook para documentação e análise
